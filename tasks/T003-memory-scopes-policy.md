# T003 Memory Scopes Policy

Status: todo

## Goal

Define which kinds of memory Avaloka may retrieve, use, expose, summarize, update, or forget.

## Candidate Scopes

- public source material
- internal project note
- user-approved care memory
- sensitive private memory
- forbidden memory

## Done Criteria

- Policy lives in `avaloka-applications/`.
- Policy includes allowed uses and forbidden uses for each scope.
- Policy includes at least 5 eval cases for memory misuse.
