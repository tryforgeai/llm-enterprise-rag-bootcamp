# T004 Minimal Agentic RAG Demo

Status: todo

## Goal

Build or fully outline the first runnable agentic RAG loop.

## Loop

```text
question
-> classify intent and risk
-> retrieve top evidence
-> choose next step
-> generate response
-> save trace
-> evaluate retrieval, decision, safety, and tone
```

## Done Criteria

- Source documents are listed.
- Trace format is used.
- Eval cases are linked.
- At least one example run is recorded in `traces/`.
