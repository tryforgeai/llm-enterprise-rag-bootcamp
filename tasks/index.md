# Task Index

This is the lightweight task queue for the bootcamp project. It stands in for a full issue tracker until a dedicated tool such as Beads is installed.

## Status Values

- `todo`: ready to work
- `doing`: currently active
- `blocked`: waiting on information or access
- `done`: completed
- `dropped`: intentionally abandoned
