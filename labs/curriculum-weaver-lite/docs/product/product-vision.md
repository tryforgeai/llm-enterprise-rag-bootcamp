# Product Vision

## Project

Curriculum Weaver Lite

## Final Vision

Curriculum Weaver Lite is a course-project prototype for pedagogy-first AI tutoring. It demonstrates how learner modeling, prerequisite graphs, source-grounded retrieval, and quiz feedback can turn scattered LLM/RAG learning materials into an ordered learning path.

## Long-Term Target User

The first target user is an AI engineering student in an LLM/RAG bootcamp who wants to convert course material into project-ready understanding.

## Long-Term Problem

Students often have access to many notes, papers, videos, and notebooks, but still do not know what to study next or how concepts connect. A good learning agent should model the learner, sequence prerequisites, retrieve source material, teach at the right depth, and test whether learning happened.

## First Use Case

Generate a prerequisite-aware learning path for understanding self-attention mathematically.

## Permanent Non-Goals

- No commercial product positioning during the course project.
- No broad curriculum coverage before the self-attention demo works.
- No heavy RAG, vector database, or agent framework in Step 1.
- No unsupported citations, invented equations, or unverifiable teaching claims.
- No collection of real student private data in the demo.

## Product Principles

- Be specific about who the product serves.
- Validate behavior before expanding scope.
- Keep active docs aligned with accepted decisions.
- Do not let implementation convenience redefine the product.

## Safety / Quality / Taste Boundaries

The system must be clear about sources, distinguish static demo data from real AI intelligence, avoid hallucinated citations, and prioritize learning sequence over flashy agent behavior. The UI should show the student's learning process, not just a generated answer.

## What Would Make This A Success

- A student can enter a goal and background, then see a coherent self-attention learning path.
- The path adapts across beginner, intermediate, and advanced profiles.
- Each lesson includes why it comes next, source cards, a code sketch, and a quiz.
- The demo visibly updates learner mastery after quiz interaction.
- Step 2 has a clear path to add real RAG, memory, evaluation, and UI tests.
