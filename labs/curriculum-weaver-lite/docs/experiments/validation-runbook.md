# Validation Runbook

## Purpose

Validate whether Curriculum Weaver Lite creates real value for an LLM/RAG bootcamp student and instructor reviewer in this first use case:

> Teach self-attention with a prerequisite-aware learning path.

## Current Stage

Course UI demo.

## Success Criteria

- A reviewer can understand the student learning flow without explanation.
- The path changes meaningfully across beginner, intermediate, and advanced profiles.
- Each lesson explains why it comes next.
- Each lesson has source cards and a quiz.
- The trace panel shows the planning logic.

## Non-Goals

- Do not validate market demand.
- Do not use private student data.
- Do not claim real adaptive intelligence before Step 2.
- Do not evaluate broad ML curriculum coverage.

## Participants / Test Subjects

Define:

- number of participants: 1-3 course peers or instructor reviewers
- inclusion criteria: familiar with LLM/RAG or learning self-attention
- exclusion criteria: no private learner records
- recruitment source: course context
- consent or boundary notes: demo only; no real educational record retention

## Test Protocol

1. Explain the product and test boundary.
2. Have the user try the smallest useful version.
3. Record behavior, not just praise.
4. Ask what worked.
5. Ask what failed.
6. Ask whether they want to continue.

## Decision Rules

Continue if:

- success criteria are met
- users show real pull
- safety/quality boundaries hold

Pause or pivot if:

- users only use when prompted
- value is unclear
- safety/quality boundaries fail
- users do not want to continue
