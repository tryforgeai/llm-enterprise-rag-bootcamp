Course project proposal

Curriculum Weaver Lite

A pedagogy-first RAG tutor that teaches self-attention by modeling the learner, ordering prerequisites, attaching source-grounded lessons, and updating mastery after quiz feedback.

Review goal Decide whether the project thesis is clear enough for the capstone: a student needs the next teachable concept, not merely the nearest chunk.
Common RAG pattern documents -> chunks -> embeddings -> answer
Curriculum Weaver thesis goal -> learner model -> prerequisite path -> grounded lesson
Course value RAG + memory + eval + trace in one visible learning loop

Problem

Similarity is not the same as teachability.

A semantic search system can retrieve passages about self-attention, but it may skip the missing ideas that make the explanation understandable: vectors, dot products, matrix multiplication, softmax, and Query/Key/Value.

Hypothesis

A prerequisite-aware learner model creates a better learning path.

The system first estimates what the learner already knows, then traverses a concept graph and retrieves material only after the next teachable concept is selected.

Step 1 scope

Static intelligence, real interaction.

  • Self-attention concept graph
  • Three learner profiles
  • Curated source cards and citations
  • Lesson, code, quiz, trace, and mastery update

Step 2 plan

Replace static pieces with real AI modules.

  • Course-material ingestion into teaching units
  • Hybrid retrieval with metadata filters
  • Learner memory and knowledge tracing
  • LLM lesson synthesis with source-grounding
  • Quiz evaluation and trace dashboard

Review questions

  4. What should the first evaluation measure: path quality, source grounding, quiz improvement, or trace usefulness?
