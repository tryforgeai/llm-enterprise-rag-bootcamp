## 〇、一句话

**硬阈值不是另一种方法，它是 sigmoid 在 γ = ∞ 时的特例——一个假装自己百分之百确定的特例。**

整条链：

```
   s          →      x = s − τ      →     p = σ(γx)     →     p > p*
相似度              相对边界的位置          命中概率            决策
(几何 ACT I)          (定位)            (决策 ACT II)     (经济学 ACT IV)
```

**γ、τ 管左半边（模型多可信）；p\* 管右半边（你多怕出事）。两边彻底解耦。**

---

## 一、五个符号

| 符号 | 名字 | 从哪来 | 什么时候确定 |
| --- | --- | --- | --- |
| **s** | 相似度 | **算出来的** — 两个向量的余弦 | 每来一个 query 算一次 |
| **τ** | 阈值 | **拟合出来的** — 从标注数据 | 离线，一次性 |
| **γ** | 陡峭度 | **拟合出来的** — 从标注数据 | 离线，一次性 |
| **x** | 中间量 | `x = s − τ` | 运行时 |
| **p** | 命中概率 | `p = σ(γx)` | 运行时，最终输出 |

τ 和 γ 是离线定好的两个常数；s、x、p 是每次查询现算的。

- **τ 是那个让 p 恰好等于 0.5 的相似度**（模型最犹豫的点）—— 决定 S 曲线摆在哪
- **γ 是曲线在那一点的斜率**（模型有多果断）—— 决定 S 曲线有多陡

## 三、s 怎么算（余弦相似度）

$$s = \cos(\vec{A}, \vec{B}) = \frac{\vec{A} \cdot \vec{B}}{\|\vec{A}\| \cdot \|\vec{B}\|}$$

真实向量 768 / 1536 维，用 3 维演示：

- 缓存问题「报销流程是什么？」→ $\vec{A} = [0.60,\ 0.80,\ 0.00]$
- 新问题「怎么报销？」→ $\vec{B} = [0.44,\ 0.87,\ 0.22]$

**分子（点积）**

```text
0.60 × 0.44 = 0.264
0.80 × 0.87 = 0.696
0.00 × 0.22 = 0.000
                ————
          点积 = 0.960
```

**分母（两个模长相乘）**

```text
‖A‖ = √(0.60² + 0.80² + 0.00²) = √1.0000 = 1.0000
‖B‖ = √(0.44² + 0.87² + 0.22²) = √0.9989 = 0.9995
```

**相除**

$$s = \frac{0.960}{1.0000 \times 0.9995} = 0.960$$

> **s 纯粹是几何量**——它只知道两个箭头夹角多大，不知道"这是不是同一个问题"。这是 ACT I 交付的全部东西。

## 四、τ 和 γ 怎么来（Platt scaling）

**不是拍脑袋定的，是拟合出来的。**

### ① 攒标注数据

从真实 query log 抽几百对，人工打标签：

| query 对 | s | 标签 y |
| --- | --- | --- |
| 报销流程 / 怎么报销 | 0.96 | 1（同问） |
| 报销流程 / 出差报销流程 | 0.93 | 1 |
| 报销流程 / 多久到账 | 0.91 | 0（不同问） |
| 报销流程 / 年假怎么请 | 0.62 | 0 |
| …（再来 500 行） | | |

### ② 跑一维逻辑回归

$$p = \sigma(w \cdot s + b)$$

```python
from sklearn.linear_model import LogisticRegression
lr = LogisticRegression().fit(S.reshape(-1, 1), y)   # S 相似度列, y 标签列
w = lr.coef_[0][0]        # 例：80.0
b = lr.intercept_[0]      # 例：-72.0
```

### ③ 换算成 γ 和 τ

$$w \cdot s + b = \gamma(s - \tau) \quad\Rightarrow\quad \gamma = w, \qquad \tau = -\frac{b}{w}$$

$$\gamma = 80, \qquad \tau = \frac{72}{80} = 0.90$$

> 这套技术叫 **Platt scaling**——专门把一个没有概率意义的分数，变成校准过的概率。

## 五、x 和 p 怎么算

τ、γ 定好后，每个 query 只做两次算术。以「怎么报销」(s = 0.96) 为例：

**① 减阈值**

$$x = s - \tau = 0.96 - 0.90 = 0.06$$

**② 乘 γ 再过 sigmoid**

$$\gamma x = 80 \times 0.06 = 4.8$$

```text
e^(-4.8)      = 0.00823
1 + 0.00823   = 1.00823
1 / 1.00823   = 0.9918
```

$$p = 0.992$$

四个 query 全算一遍：

| query | s | x = s−0.90 | γx = 80x | e^(−γx) | **p** |
| --- | --- | --- | --- | --- | --- |
| 怎么报销 | 0.96 | +0.06 | +4.8 | 0.0082 | **0.992** |
| 出差报销 | 0.93 | +0.03 | +2.4 | 0.0907 | **0.917** |
| 多久到账 | 0.91 | +0.01 | +0.8 | 0.4493 | **0.690** |
| 年假怎么请 | 0.62 | −0.28 | −22.4 | 5.4e+9 | **≈ 0** |

## 六、为什么必须有 γ

### 理由 1：没有 γ，公式在数值上根本不能用

sigmoid 的有效工作区是 $x \in [-4, +4]$。但余弦相似度基本挤在 0.80~0.99，$s - \tau$ 的典型幅度只有 **±0.05**——**差了将近 100 倍**。

γ = 1 时把四个 query 算一遍：

| query | x | p = σ(x) | 系统说 |
| --- | --- | --- | --- |
| 怎么报销 | +0.06 | **0.515** | 51.5% |
| 出差报销 | +0.03 | **0.507** | 50.7% |
| 多久到账 | +0.01 | **0.502** | 50.2% |
| 年假怎么请 | −0.28 | **0.430** | 43% |

「年假怎么请」和「报销流程」八竿子打不着，系统却说有 **43% 可能是同一个问题**；最该命中的也才 51.5%。**四个数全挤在 0.43~0.52，这个系统等于什么都没说。**

> γ 的作用是**换算单位**：把相似度那把「毫米刻度」的尺子，换算成 sigmoid 听得懂的「米」。
> 类比：sigmoid 是一台以米为单位的仪器，相似度差是以毫米测出来的。γ 就是那个 1000 倍的换算系数。没有它，仪器指针不动。

### 理由 2：γ 是模型能力的体温计

γ 衡量的是——「同问」和「不同问」两堆样本的相似度分布**分得开还是分不开**：

```text
分得开（γ 大）：   ▁▂█▆▂▁          ▁▂█▇▃▁
                  不同问              同问
                       ↑ 中间有空隙

分不开（γ 小）：   ▁▂█▇█▆█▃▂▁
                   两堆糊在一起
```

**拟合出来的 γ 很小 = 你的 embedding 模型在这个任务上没有区分力。**这时候再怎么挪 τ 都是徒劳——不是阈值定错了，是**尺子本身不准**。该换模型、加 reranker、或做领域微调。

### 理由 3：τ 和 γ 是两件不同的事

$$p = \sigma(\underbrace{\gamma}_{\text{斜率}} \cdot s - \underbrace{\gamma\tau}_{\text{截距}})$$

| 参数 | 控制 | 由什么决定 |
| --- | --- | --- |
| **τ** | 边界**在哪** | 校准结果（模型最犹豫的那一点） |
| **γ** | 边界**多硬** | 模型能力（分数有多可信） |

一维逻辑回归有且只有这两个参数。只有 τ 没有 γ，等于只能画截距、画不了斜率——**相当于假设"所有模型的可信度都一样"**。

### 拉伸与压缩

γ 是横轴缩放系数。过渡区宽度约 $4/\gamma$：

| γ | 过渡区宽度 | 形状 |
| --- | --- | --- |
| 100 | 0.04 | 几乎是阶跃 |
| 20 | 0.2 | 明显的 S |
| 2 | 2.0 | 几乎是直线 |

γ → ∞ 就压回台阶，退化成硬阈值 `if s > τ`。

## 七、p 拿来干嘛：p\* 与期望损失

> ⚠️ **注意区分**：τ 和 γ 是**校准参数**，只反映模型能力，和你怕不怕犯错**无关**。真正的命中判据是**另一个门槛 $p^*$**，它从成本算出来。（课上一开始容易把这两件事混起来。）

命中划算，当且仅当期望收益为正：

$$\underbrace{p \times G}_{\text{猜对，省下钱}} \;>\; \underbrace{(1-p) \times C}_{\text{猜错，赔的钱}}$$

解出：

$$p^* = \frac{C}{G + C}$$

- $G$ = 命中省下的成本（检索 + 生成，约 \$0.01）
- $C$ = 答错的代价，**取决于业务**

> ⚠️ **课后修正（讲义 p.29）**：上式是 $\kappa = 0$ 的特例。讲义的完整版是
>
> $$\text{VoS} = pg - (1-p)L - \kappa \qquad\Longrightarrow\qquad \textbf{serve iff}\quad p > \frac{L+\kappa}{g+L}$$
>
> 多出来的 $\kappa$ 是**做这次查找本身的成本**（embedding + 向量检索 + 决策）。所以真实门槛比这里算的**更高**。$\kappa$ 接近 $g$ 时 $p^*\to 1$ —— **查缓存本身跟重算差不多贵，就不该有这个缓存**。
>
> 另见 [`act2-decision.zh.md`](act2-decision.zh.md)：$d'$ 与 γ 的换算、τ 就是两峰中点。

### 场景 A：内部 IT 问答（$C = \$0.20$）

$$p^* = \frac{0.20}{0.01 + 0.20} = 0.952$$

| query | p | p > 0.952？ | 决策 |
| --- | --- | --- | --- |
| 怎么报销 | 0.992 | ✅ | **命中** |
| 出差报销 | 0.917 | ❌ | 走完整 RAG |
| 多久到账 | 0.690 | ❌ | 走完整 RAG |
| 年假怎么请 | ≈0 | ❌ | 走完整 RAG |

### 场景 B：药品剂量问答（$C = \$500$）

$$p^* = \frac{500}{0.01 + 500} = 0.99998$$

四个全都不达标 → **这个场景几乎不该开 Query→Answer 缓存。**

> 这个结论不是靠直觉喊出来的，是**算出来的**。这正是 ACT IV「The Economics」存在的意义。

## 八、什么时候动 τ、什么时候动 γ

### 情况 A：模型没变，业务变了 → 只动 p\*（曲线不动）

同一个 embedding 模型（γ = 80, τ = 0.90），换场景：

| 业务 | 答错代价 | p\* | 「多久到账」(p=0.690) |
| --- | --- | --- | --- |
| 内部 IT 问答 | 低 | 0.952 | ❌ 不命中 |
| 商品促销问答 | 极低（C=\$0.005） | 0.333 | ✅ 命中 |
| 药品剂量问答 | 极高 | 0.99998 | ❌ 不命中 |

**同一个 query、同一个相似度、同一个模型**，因为业务代价不同，结论完全相反。

### 情况 B：业务没变，模型升级了 → γ 变大（曲线变陡）

还是报销场景，把通用 embedding 换成领域微调模型：

| | 「怎么报销」（该命中） | 「多久到账」（不该命中） | 差距 |
| --- | --- | --- | --- |
| 旧模型 | 0.96 | 0.91 | **0.05**，糊在一起 → γ ≈ 20 |
| 新模型 | 0.97 | 0.72 | **0.25**，分得很开 → γ ≈ 90 |

τ 可以完全不动，但曲线变陡了。

## 九、完整流程（伪代码）

```python
# ===== 离线，一次性 =====
w, b = fit_logistic(similarities, labels)
γ, τ = w, -b / w                  # γ=80, τ=0.90   ← 模型能力

p_star = C / (G + C)              # 0.952          ← 业务风险

# ===== 运行时，每个 query =====
def lookup(query):
    q_vec = embed(query)
    cached, s = vector_search(q_vec)          # ① s：几何
    x = s - τ                                 # ② x：相对边界的位置
    p = 1 / (1 + exp(-γ * x))                 # ③ p：概率
    if p > p_star:                            # ④ 决策：概率 vs 成本
        return cached.answer
    return full_rag(query)
```

## 十、留存句

- **硬阈值是 sigmoid 在 γ=∞ 时的特例——一个假装自己百分之百确定的特例。**
- **τ 说的是「边界在哪」，γ 说的是「我有多大本事看清边界」，p\* 说的是「我怕不怕犯错」。**
- **γ 拟合得小，别调阈值——换模型。**
- **门卫类比**：τ = 警戒线画在离门多远；γ = 门卫的视力。高度近视的门卫，无论把线画在哪都会放错人——**他需要的不是重新画线，是一副眼镜。**
