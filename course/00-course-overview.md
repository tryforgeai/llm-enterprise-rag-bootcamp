## Main Topics

- Introduction to language models
- High-dimensional geometry
- Retrieval
- Retrieval funnels
- Vision
- Prompts
- Graph-based retrieval
- Enterprise RAG challenges
- Agentic RAG
- Text2SQL
- Fine-tuning
- Evals

## Skills To Extract For My Work

- How embeddings represent text, image, audio, and video signals
- How retrieval pipelines are built and evaluated
- How to choose chunking and retrieval strategies
- How to combine dense, sparse, graph, and reranking retrieval
- How to build guardrails around generated answers
- How to evaluate retrieval and generation quality
- How to apply RAG to Avaloka AI memory and knowledge systems
- How to turn retrieval into agent behavior, tool use, and eval loops

## Not The Main Focus For Me

These are useful, but secondary for now:

- fraud detection
- tabular anomaly detection
- healthcare-specific applications
- deep GPU infrastructure
- full production MLOps

## Primary Personal Goal

Use this course to upgrade Avaloka AI from:

```text
LLM response + local memory
```

to:

```text
agent loop
+ knowledge retrieval
+ memory retrieval
+ safe next-step decisions
+ eval gates
+ multimodal ingestion
+ graph-shaped understanding
```
